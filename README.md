**版本 V0.2.2　·　作者 [baiai.org](https://baiai.org) QQ:951424960 微信:BH8GYP　·　协议 [Apache-2.0](LICENSE)**

带图形界面的 **QQ 多角色 AI 主动消息桌面应用**。

导入 SillyTavern 角色卡（PNG / JSON / YAML）或自己写人设，让 AI 角色住进 QQ：
你在 QQ 里说话，它用对应人格回复；它还能在每天固定时刻、你长时间没说话时、
或在活跃时段内随机地**主动找你聊天**。V0.2 起，角色还能**看图、发图、听语音、回语音**。

全部操作都在图形界面里完成，交付物是**一个安装包 EXE**：双击安装、有桌面图标、
随时可以从「Windows 设置 → 应用」里卸载。

> **QQ 接入方式只有一种：QQ 官方机器人**（QQ 开放平台）。
> 在 [q.qq.com](https://q.qq.com) 创建机器人应用，把 **AppID / AppSecret** 填进程序即可 ——
> 合规、不需要小号、没有封号风险。

```
┌────────────────────────────────────────────────────────┐
│  图形界面（PySide6 + 系统托盘）                            │
│  仪表盘 · 机器人 · 角色管理 · 模型路由 · 消息设置 · 对话 · 设置 │
└──────────────┬─────────────────────────────────────────┘
               │ 本机接口（127.0.0.1:8765，不出你的电脑）
┌──────────────▼─────────────────────────────────────────┐
│  Bot 进程：收发消息 · 角色对话 · 记忆 · 主动消息调度          │
└──────────────┬─────────────────────────────────────────┘
               │ WebSocket 网关（收）+ REST 接口（发）
┌──────────────▼─────────────────────────────────────────┐
│  QQ 官方机器人开放平台（api.sgroup.qq.com）                │
└────────────────────────────────────────────────────────┘
```

## 1. 功能一览

| 功能 | 能做什么 |
|---|---|
| **多角色** | 导入 SillyTavern 角色卡（PNG / JSON / YAML，含 Chub 卡片），或自己写人设；每个角色有独立的描述 / 性格 / 场景 / 示例对话 / 系统指令、头像与音色；编辑时哪个字段没写会明确提示 |
| **多机器人** | 同时接入多个 QQ 机器人，每个绑定一个角色，凭据、消息目标互不干扰 |
| **主动消息** | 定时（如 09:00 / 21:00）、你空闲超过 N 小时、活跃时段内随机三种触发；带免打扰时段、每日上限、最小间隔、发送概率；每条没发出去的消息都有可读原因可查 |
| **看图** | 你在 QQ 发图片，角色通过「图像理解」线路真正看到内容后回复 |
| **发图** | 角色回复末尾写 `[IMG] 描述` 时，自动用「图像生成」线路画一张发给你 |
| **听语音** | 你发语音，QQ 官方平台随消息推送的参考转写直接给角色听（**零配置、不用配任何线路**），语音音频也会存档，可在对话列表里回放 |
| **回语音** | 角色按概率把整条回复改成语音发回来（默认 5%，可在「消息设置」页调，也可按机器人单独设置）；TTS 支持百炼（默认，情感 / 笑声 / 叹息标签 + 语气指令）、edge-tts（免费 300+ 音色）、OpenAI 兼容三种引擎 |
| **模型路由** | 主模型 / 图像理解 / 图像生成 / 文字转语音四个能力**各走各家的 API**；每个线路带常用服务商预设（选一下自动填好地址与候选模型）、「获取模型列表」（拉真实清单点选即填）、「测试线路」（按界面当前值当场验证，不用先保存） |
| **记忆** | 对话分级管理：**7 天内原文进上下文，7~15 天自动压缩成摘要进上下文，15 天以上只归档**；长期记忆从对话中自动抽取，下次聊天带相关记忆进来 |
| **常驻与省心** | 系统托盘常驻、最小化到托盘、可选开机自启、启动自动检查更新（可手动检查 / 跳过版本 / 不再提示） |
| **优雅降级** | 任何媒体 / 模型线路未配置或失败，自动退回纯文字，聊天不会被打断；LLM 全部重试失败时用兜底话术 |

## 2. 系统要求与下载安装

* **系统**：Windows 10 / 11（64 位）。无需安装 Python 或其它运行库。
* **下载**：到 [Releases 页面](https://github.com/baiai-org/BaiAi-Tavern/releases) 获取安装包：

| 文件 | 说明 |
|---|---|
| `BaiAi-Tavern-V0.2.2.exe` | Windows 安装包（约 77MB，单文件，安装 + 卸载都在里面） |
| `BaiAi-Tavern-V0.2.1.exe` | 上一版（补丁版） |
| `SHA256SUMS.txt` | 校验值，下载后可自行核对：`certutil -hashfile "BaiAi-Tavern-V0.2.2.exe" SHA256` |

* **安装**：双击 → 选择安装位置（默认 `%LOCALAPPDATA%\Programs\BaiAi-Tavern`，
  按用户安装、不需要管理员权限）→ 勾选是否创建桌面 / 开始菜单快捷方式 → 完成。
  安装前会自动关掉正在运行的旧版本（升级 / 修复，用户数据不动）。
* **卸载**：「Windows 设置 → 应用」，或重新运行安装包选「卸载」；
  **卸载默认保留你的配置与聊天记录**（想连数据一起删见 [第 7 节](#7-数据与隐私)）。
* **自动更新**：启动后后台检查 GitHub Releases（每 6 小时最多一次，不弹窗打扰）。
  发现新版会提醒，可选**立即更新 / 跳过此版本 / 不再提示 / 稍后再说**；
  更新带下载进度条与 SHA256 校验，装完自动重启为新版，配置与数据保留。
  主窗口左下角**「安装与更新」**可随时手动检查、查看安装信息、重装修复或卸载。
* **首次运行**会弹出 6 步配置引导（见下节），准备好「LLM 接口的 API Key」
  和「QQ 官方机器人的 AppID / AppSecret」即可。

## 3. 快速开始（约 10 分钟）

### 第 1 步：创建 QQ 机器人（一次性，约 5 分钟）

1. 打开 [q.qq.com](https://q.qq.com) → 用手机 QQ 扫码登录 → **创建机器人**（个人开发者即可）；
2. 在「开发设置」里拿到 **AppID** 与 **AppSecret**；
3. 把机器人**加为你的好友**（或拉进群并 @ 它）—— 官方平台只允许机器人先收到消息才能回复；
4. （可选，想用「主动找你」才需要）在开放平台为机器人申请**主动消息权限与额度**，
   未开通时机器人只能被动回复你。

### 第 2 步：启动程序，跟着 6 步引导配置

启动后自动弹出「配置引导」，固定 6 步，跟着走一遍就能用：

| 步骤 | 内容 |
|---|---|
| 1 欢迎 | 说明接入的是 QQ 官方机器人（不需要小号），以及需要准备的三样东西 |
| 2 LLM 接口 | **下拉选择常用服务商**（自动填好 Base URL）→ 填 API Key → 点「获取模型列表」从上游拉取模型并在列表里点选 → 点「测试连接」当场验证 |
| 3 QQ 配置 | 填官方机器人 **AppID / AppSecret**（附申请入口），并**指定这个机器人由哪个角色说话** |
| 4 角色卡 | 一键导入**内置的 3 个默认角色**，或导入 PNG / JSON / YAML 角色卡（导入后立即出现在列表里；卡片本身没写的字段会明确提示） |
| 5 主动消息 | 选择定时 / 空闲 / 随机触发与每日上限（默认保守配置） |
| 6 完成 | 配置检查（缺什么会标红），点「完成」立即生效 |

也可以随时点「取消引导（我自己配置）」跳过，之后在「系统设置」里配；
想再看一遍引导：**系统设置 → 配置引导**，或把 `config.yaml` 里的 `app.onboarding_done` 改成 `false`。

### 第 3 步：验证

1. 在 QQ 里给机器人发一条 `hi`；
2. 角色用对应人格回复 —— 配置完成；
3. 没回复时看**仪表盘**页面：网关状态、最近收到的消息、每次没发出去的「最近跳过原因」都列在那里。

## 4. 页面说明（每页能做什么）

启动后窗口自适应屏幕（不小于 1160×760），左侧依次是：

| 页面 | 能做什么 |
|---|---|
| **仪表盘** | 机器人连接状态、已记住的私聊对象（可点「忘记已记住的」重来）、最近消息、主动消息「最近跳过原因」、一键「立即触发一次」主动消息 |
| **机器人** | 新增 / 停用机器人，填名称 / AppID / AppSecret，**给每个机器人绑定一个角色**，测试连接，**按机器人单独设置生图风格**（自动按人设匹配 / 动漫 / 写实 / 自定义风格关键词 / 不指定） |
| **角色管理** | 导入内置角色 / 角色卡，编辑人设（六个字段 + 补充设定），换头像，**点「音色」按钮试听并按角色调节语速 / 音调 / 音量**，启用 / 停用 / 删除 |
| **模型路由** | 图像理解 / 图像生成 / 文字转语音三条线路，各填 Base URL / Key / 模型；服务商预设、获取模型列表、**测试线路（按表单当前值测试，不用先保存）**。主模型（文字对话）在「系统设置 → LLM」配置 |
| **消息设置** | 定时 / 空闲 / 随机触发的开关与参数、活跃时段与免打扰、每日上限、最小间隔、发送概率；富媒体行为（语音回复概率 / 允许发图 / 语音字数上限）。**顶部可切换「全局设置」或某个机器人**：给某个机器人单独设置后它用自己的配置，未单独设置的项继续跟随全局。改完点「保存并应用」 |
| **对话查看** | 查看与每个角色的全部聊天历史：**按月 / 按天筛选、关键词搜索**，图片消息直接显示**缩略图**（点开即看），语音消息显示**播放徽标 + 转写文字**（点开即播） |
| **系统设置** | 主模型（LLM）配置、QQ 官方机器人凭据、开机自启与托盘行为、配置引导入口 |
| **日志** | 浏览 Bot / 界面日志（排查「为什么没回我」的第一站） |

左下角还有两个入口：**「安装与更新」**（检查更新 / 安装信息 / 重装 / 卸载）
与**「关于」**（版本、作者、引用的全部开源项目及主页链接，可整份复制）。

### 聊天时的操作

* **普通聊天**：直接在 QQ 聊天窗口说话即可；
* **临时换角色**：发 `#角色名 消息`（如 `#苏苏 在吗`）；
* **发图**：直接发图片，角色看图后回复（走「图像理解」线路）；
* **收图**：角色回复末尾出现 `[IMG] 描述` 时自动生图并发给你（走「图像生成」线路）；
  生图前会先读角色人设——**二次元角色出动漫风格、真实风格角色出写实照片风格**
  （生图风格在「机器人」页或「消息设置」页按机器人单独设置：自动匹配 / 动漫（京阿尼风格）/ 写实 / 自定义风格关键词 / 不指定；
  绘图描述、风格（含自定义关键词）与光影基调先经主模型汇总理解融合——无明确要求时背景默认白天阳光灿烂，
  有明确要求（夜晚 / 黄昏等）则按要求；生图像素限制在 1000×1000 以内：生图请求就带画布尺寸（size 参数 + 提示词））；
* **发语音**：直接发语音消息，平台转写自动给角色听，无需任何配置；
* **回语音**：按「消息设置」里的语音回复概率（默认 5%）随机把回复改成语音，可按机器人单独设置。

### 多机器人 + 多角色

一个「机器人」= 一个 QQ 官方机器人应用（一套 AppID / AppSecret），**绑定一个角色**。
同一个程序能同时运行多组「机器人 + 角色」，凭据、主动消息目标、绑定角色互相独立、互不串台。
在**机器人**页面点「＋ 新增机器人」即可；停用某个机器人后，它的消息与主动消息都会被跳过，
并在日志里给出原因。

群里多个机器人同时在线时**@ 谁谁回答**：开了「接收所有消息」的群里每条消息平台都会推给
每个机器人，本程序会精确识别消息里 @ 的是哪个机器人（@ 占位、`mentions` 的
`is_you` 标记与多种身份字段都会匹配，兼容平台新旧两种下发格式）——@ 了别人
（包括别的机器人）时本机器人让路不插话；没有 @ 任何人的普通群消息按「响应没有 @
的群消息」开关处理（系统设置 → QQ 机器人，默认开）。官方平台可能对同一条消息
重复推送，且 @ 事件与全量事件可能同 id 先后到达（顺序不保证）——程序按消息 id
做状态化去重：已回复过的不再回第二遍；先到的全量事件若没 @ 到本机器人被让路，
后到的 @ 事件仍会正常回复（不会吞消息）。

## 5. 主动消息：怎么触发、怎么排查

| 触发方式 | 说明 | 默认 |
|---|---|---|
| 定时触发 | 你设定的时间点（如 09:00 / 21:00） | 开 |
| 空闲触发 | 你超过 N 小时没说话 | 6 小时 |
| 随机触发 | 活跃时段内随机时间 | 关（间隔 120–300 分钟） |
| 手动触发 | 仪表盘「立即触发一次」 | — |

每次触发会依次检查：**总开关 → 免打扰时段 → 活跃时段 →（空闲条件）→ 每日上限 → 最小间隔
→ 发送概率**，再选出候选角色（今日发言少的优先，避免连续同一角色发言），
带上最近对话与相关记忆生成消息，按官方单条长度拆分发送。

任何一步不满足都会**记录可读原因**（例如「当前处于免打扰时段 23:00-08:00」），
在**仪表盘 / 消息设置**页面直接可见——「她为什么没找我」的答案都在这里。

**主动消息发给谁（openid）**：官方接口不能按 QQ 号发送，只能按 `openid`。程序有三种方式：

1. **自动记住**（推荐）：你先给机器人发一条消息，程序就记住这个 `openid`；
   仪表盘能看到「已记住的私聊对象」，也可点「忘记已记住的」重来；
2. **手动填写**：QQ 配置里的「主动消息目标」直接填 `openid`；
3. **发到群**：填「主动消息群」`group_openid`，填了就优先发群。

**官方平台的规则（程序已按这些实现）**：

* 被动回复有效期 5 分钟，同一消息最多回复 5 次（程序自动处理）；
* 主动消息需要申请权限与额度，未开通时平台返回 `22009 / 30402`，界面会写明原因；
* 机器人网关必须在线才能发消息——程序关着时机器人不在线；
* **沙盒模式**：QQ 配置里勾选后只对沙盒测试成员生效，适合先跑通流程。

常见错误码（程序会翻译成人话）：

| 错误码 | 含义 |
|---|---|
| 100007 / 10004 | AppID 无效，或机器人状态异常（被封禁 / 已删除） |
| 100016 | AppID 或 AppSecret 不正确 |
| 11244 | 机器人未加入该群，或群聊消息权限不可用 |
| 22009 / 30402 | 主动消息额度用尽 / 未开通主动消息权限 |
| 50054 | 被动回复已过期（超过 5 分钟） |

## 6. 模型线路（看图 / 发图 / 语音用什么服务）

四个能力相互独立，**任何一条不配就等于关闭该能力，文字聊天不受影响**：

| 能力 | 在哪配 | 说明 |
|---|---|---|
| 文字对话（主模型） | 系统设置 → LLM | 兼容 OpenAI 协议的任意端点。选服务商预设 → 填 Key → 获取模型列表点选 → 测试连接 |
| 图像理解 | 模型路由 → 看图 | 多模态端点（DeepSeek-VL / 通义 VL / GPT-4o 等）；「测试线路」会用内置红色测试图验证模型真的看了图 |
| 图像生成 | 模型路由 → 生图 | OpenAI 兼容 `/images/generations` 或 Gemini 原生接口（nano banana 系列一键预设）；对参数挑剔的端点会自动降级参数重试，不用手动迁就 |
| 文字转语音 | 模型路由 → TTS | 默认**阿里云百炼**（模型与音色已预填，只需粘贴 Key；自动启用情感 / 拟声标签与语气指令）；也可切 edge-tts（免费、无需 Key、300+ 音色）或 OpenAI 兼容 |

* 每条线路都支持：服务商预设（选一下自动填地址与候选模型）、「获取模型列表」、「测试线路」
  （按界面当前值当场测试，**不用先保存**）；
* **本地 / 自托管服务**（vLLM / SGLang 等）：Base URL 填 `http://你的局域网IP:端口/v1`，
  **Key 可以留空**；
* 每个角色可在角色管理里单独指定**音色**并试听；任何线路失败都会自动退回纯文字。

## 7. 数据与隐私

* **数据都在你本机的数据目录**：安装版在 `%APPDATA%\BaiAi-Tavern`（安装目录里的
  `data\` 是程序文件），绿色版在 `<程序目录>\data`：

| 内容 | 位置 |
|---|---|
| 配置（含你填的 Key） | `config.yaml` |
| 角色 / 聊天记录 / 记忆 | `bot.db`（SQLite） |
| 角色卡与头像 | `characters\` |
| 收发的语音 / 图片临时文件 | `media\`（默认 3 天后自动清理） |
| 日志 | `logs\` |

* 所有配置都能在界面里改，改完即生效；高级用户也可以直接编辑 `config.yaml`
  （每个字段都有注释，Bot 会在 1 分钟内自动热重载，也可在界面点「重载配置」）。
  支持 `${ENV_VAR}` 形式引用环境变量，例如 `api_key: "${DEEPSEEK_API_KEY}"`。
* **环境变量**（一般用不到）：`BAIAI_DATA_DIR`（换数据目录位置）、`BAIAI_CONFIG`
  （指定配置文件）、`BAIAI_HOME`（指定程序根目录）；旧的 `QQAI_*` 名字仍兼容。
* **卸载默认保留数据**；想彻底清干净：卸载时选「删除数据」，或手动删掉数据目录。
* 配置 / 聊天记录 / 头像 / 语音**从不离开你的电脑**（除发给你所选的模型服务与 QQ 平台）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 提示「尚未填写 AppID / AppSecret」 | 这是**官方机器人唯一的必需配置**：去 [q.qq.com](https://q.qq.com) 创建应用后填到「系统设置 → QQ」；填完点「测试连接」 |
| 测试连接报 `100016` | AppID 或 AppSecret 填错了（注意别把「机器人 QQ 号」当 AppID） |
| 测试连接报 `100007` | AppID 无效，或机器人状态异常（未上线 / 被封禁 / 已删除） |
| 网关连上了但收不到消息 | 官方平台要求先有人给机器人发消息；确认机器人已加好友（或已入群并 @ 它），且 `intents` 为 33554432 |
| 机器人收到了但不回 / 回复「尚未配置 LLM」 | 主模型没配好或线路不通：系统设置 → LLM 点「测试连接」；本地局域网地址 Key 留空即可 |
| 主动消息发不出去 | 官方「主动消息」需要申请权限与额度；界面上「最近跳过原因」会写明（如 `22009`）。另外必须先有 openid：让对方先发一条消息 |
| 发图了角色说「看不到」 | 「模型路由 → 看图」线路没配置或测试没通过；任何线路不通时自动退回纯文字 |
| 界面提示「无法连接到 Bot 进程」 | 看 `data/logs/bot.log`；多为 `api.port` 被占用或缺少 `bot.exe` |
| LLM 报错 / 超时 | 用「系统设置 → 测试连接」定位；失败会自动重试，全部失败时使用兜底话术 |
| 「获取模型列表」失败 | 该网关可能不支持 `/models`（部分中转站）；先用「测试连接」确认 Key 与地址，再手动填模型名 |
| 导入角色卡后某些框是空的 | 多数 Chub 卡片只写「描述 + 开场白」，性格 / 场景等字段在卡片里就是空的（导入时会明确列出）；可在「编辑」里补全 |
| 角色编辑里看到 `{{char}}` / `{{user}}` | 标准占位符，聊天时自动替换为角色名 / 你的昵称，保留即可；「补充设定」里的大段 HTML 是卡片自带的展示页，不影响对话 |
| 托盘图标不见了 | Windows 会折叠托盘图标，展开即可；双击图标恢复窗口 |
| 想换数据位置 | 设置环境变量 `BAIAI_DATA_DIR=D:\BaiAi\data` 后启动 |
| 用任务管理器强杀了界面，Bot 还在跑 | 在任务管理器里结束 `bot.exe`，或重新打开界面后点「停止 Bot」 |
| 安装完桌面没有图标 | 安装时勾选了「不创建桌面快捷方式」；重新运行安装包一次即可（覆盖安装，数据不动） |
| 安装时报「bot.exe: Permission denied」/「以下文件复制失败」 | 旧版本还在运行（界面或 `bot.exe` 占着文件）。新版安装程序会**自动关掉**它们；若仍失败，手动退出托盘里的程序（或结束任务管理器里的 `bot.exe`）后重试 |
| 卸载后想彻底清干净 | 卸载时勾选「删除数据」；或手动删掉数据目录（见第 7 节） |
| 旧版本升级后配置里还有 NapCat 字段 | 首次启动会自动清理并备份为 `config.yaml.bak`；程序已不再支持第三方协议 |

## 9. 已知限制

* **主动消息受官方平台限制**：需要申请权限，且有每日额度；未开通时只能被动回复。
* 官方接口按 `openid` 发送，因此「主动找谁」需要先有一次对话（或手动填 openid）。
* 长期记忆采用关键词重叠加权检索（不引入向量库），以换取小体积与低内存占用。
* 目前只提供深色主题。
* 富媒体（看图 / 生图 / 语音）依赖各线路的服务商实现，换厂商时请在「模型路由」页
  用「测试线路」逐个验证；任何线路未配置或失败都会自动退回纯文字，不影响正常聊天。
